# Security and privacy

This library runs offline and needs no credentials. Please report a suspected
security or privacy issue privately through GitHub's repository security
advisory feature rather than a public issue.

Do not include live tokens, private keys, voter answers, addresses, recordings,
logs, sessions, or other personal data in a report. A maintainer can request a
minimal synthetic reproduction if needed.

The supported version is the current `main` branch. Because this is reference
research software rather than a hosted service, no response-time commitment is
made.
